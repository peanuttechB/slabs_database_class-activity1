Introduction to Information Systems

Application: WhatsApp

1. Hardware

WhatsApp relies on physical devices to function. These include:
- Smartphones, tablets and computers used by people to access the application.
- Servers that process and store information.
- Network equipment such as routers and switches.
- Internet infastructure that allows messages and other data to travel between devices.

2. Software

WhatsApp uses different types of software to operate.
- Application software: WhatsApp is the application that allows users to send messages, make voice calls and video calls and share files.
- Operating Systems : WhatsApp runs on operating systems such as Android, iOS, Windows and MacOS, depending on the device.
- Server software : Software running on WhatsApp's servers helps manage communication and deliver messages between users.

3. Data

WhatsApp uses different types of data to provide its services.
Examples include:
- Messages sent by users.
- Phone numbers used to identify accounts
- Timestamps showing when messages are sent or received.
- Images, videos, voice notes and ducuments shared by users.
- Delivery and read-status information.

4. People

Different people interact with or support the WhatsApp information System.
- Users: People who send and receive messages.
- Developers: People who create and maintain the application.
- System Administrators: People who help maintain the computer systems and servers
- Security Specialists: People who help protect accounts and systems againts security threats.
- Business Users: Businesses that use WhatsApp to communicate with customers.

5. Process

The main process of sending a WhatsApp message follows these steps:
- A user opens the application and selects a contact.
- They then type a message and presses the send button.
- The app processes the message and sends its through the communication network.
- WhatsApps's systems help route the message to t he receiver.
- The recipient's device receives the message when it can be delivered.
- WhatsApp displays the appropriate delivery status to the sender.


Raw Data and Meaningful Information 

Raw Data

One example of raw data collected by WhatsApp is a message timestamp, such as 08:30. A timestamp is a recorded fact that indicates when an event occured.

Transformation of Data into Information

WhatsApp can use message timestamps and delivery-status data to show users when a message was sent, delivery-status data to show users when a message was sent, delivered or read where the relevant status is 
available.
The system processes these individual facts and displays them in a form that users can understand.

How the Information Supports Decision-Making

The delivery and read-status help users decide whether to wait for a response, follow up with someone or contact them through another method.
This demonstrates the difference between raw data and meaningful information. Raw data consists of individual recorded facts, while information is data that has been processed and presented in a useful context.

Conclusion

WhatsApp is an example of an information system because it combines hardware, software, data, people and processes to provide a communication service. These components work together to process data and provide useful information that helps users communicate and make decisions.
